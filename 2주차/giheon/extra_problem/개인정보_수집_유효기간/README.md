# [타깃 넘버]

### 1. 접근 방식
 - 처음에 접근한 방식은 단순히 년,월,일을 비교하고 계산할 생각만 했음. 근데 생각해보니 12로 mod연산 했을 때 예외 케이스가 생긴다는 것을 깨달음. 여기서부터 막막해서 답 찾아봄

### 2. 핵심 로직
 - 년,월,일을 연산을 통해 하나의 큰 일로 바꾸는 것이 핵심.
 - 문제에서 월별로 28일로 통일한다고 한 것이 열쇄.

### 3. 시간 복잡도
 - O(N)

### 4. 느낀 점 / 어려웠던 점
 - 년도, 월, 일을 따로 비교할 생각만 했지 일을 기준으로 하나의 큰 수를 만들어볼 생각을 못했었음. 번개가 번쩍했음.

### 5. 풀이 시간
 - 30분 보다가 정답 찾아봄
