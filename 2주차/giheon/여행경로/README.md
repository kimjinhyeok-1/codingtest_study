# [여행경로]

### 1. 접근 방식
 - 그래프를 알파벳 오름차순으로 정렬해서 하나씩 제거하면서 전위 순회를 하려고 했음.
 - but 정답이 아니였음. 그래서 고민하다가 정답을 확인함.

### 2. 핵심 로직
 - graph 생성 시 내림차순으로 정렬하여 스택처럼 하나씩 값을 pop하면서 탐색.
 - 더 이상 탐색할 곳이 없을 때 후위 순회처럼 하나씩 answer에 append

### 3. 시간 복잡도
 - O(NlogN)

### 4. 느낀 점 / 어려웠던 점
 - 딕셔너리의 값을 pop으로 하나씩 꺼내는 로직을 처음 알게되었음.
 - 오일러 경로 방식? 을 알게됨
