# [아이템_줍기]

### 1. 접근 방식
- 갈 수 있는 곳 grid로 미리 만들어서 bfs 돌리기

### 2. 핵심 로직
- bfs는 전형적인 bfs인데 직사각형을 고려한 grid 만들기가 메인이였음

### 3. 시간 복잡도
- O(N^2) 시간 복잡도를 고려하는 문제는 아니였음 어차피 N이 100 이라

### 4. 느낀 점 / 어려웠던 점
- 만드는 과정에서 2배하는건 상상도 못함 ㄷ 자 모양일 때를 고려한다는 걸 생각하지 못함
- 코드 찾아보고 해결함

### 5. 풀이 시간
- 서칭하고 풀어서 다음주에 한번더 풀어봐야될듯
