# [멀리 뛰기]

### 1. 접근 방식
 - 사실 재대로 된 접근법을 알았다기 보다는 n이 1일때부터 6될때까지 쭉 다 생각해봤는데 가짓수가 피보나치 수열 형태로 증가하는 것을 확인하고 적용해봤더니 문제가 풀림.

### 2. 핵심 로직
 - n칸에 도달하는 방법의 수는 n-1칸에 도달하는 방법의 수와 n-2칸에 도달하는 방법의 수를 더한 값임.

### 3. 시간 복잡도
 - O(N)

### 4. 느낀 점 / 어려웠던 점
 - n칸에 도달하는 경우의 수는 n-2번째 칸에서 2칸을 점프해서 오거나, n-1번째 칸에서 1칸을 점프해서 오는 경우의 수 밖에 없음.
 - 피보나치 규칙을 찾아서 풀 수 있었지만 위의 핵심 개념은 떠올리지 못 한 상황이였었음.
 - 접근법에 대해 다시 한 번 생각해 볼 수 있었음.

### 5. 풀이 시간
 - 15분
