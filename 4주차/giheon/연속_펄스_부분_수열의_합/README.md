# [멀리 뛰기]

### 1. 접근 방식
 - 펄스 수열은 두가지 경우의 수 밖에 없어서 두가지 경우의 수일 때의 연속 펄스 부분 수열을 모두 만듬.
 - 두가지 경우의 수에서 카데인 알고리즘을 적용하여 부분 수열의 합 최대값을 구함.

### 2. 핵심 로직
 - 연속했을 때 값이 최대인지, 아니면 끊었을 때 최대인지 판단하여 최대인 값으로 DP를 업데이트.

### 3. 시간 복잡도
 - O(N)

### 4. 느낀 점 / 어려웠던 점
 - 부분 수열의 합 최댓값을 어떻게 구해야하지? 고민이 있었음.
 - 완전 탐색을 고려해봤으나 N이 50만....
 - 찾아봤는데 부분 수열의 합 최대값을 구하는 알고리즘 중에 카데인 알고리즘이라는게 있다는 것을 알게됨.

### 5. 풀이 시간
 - 40분 정도 고민하다가 정답을 찾아봄.
