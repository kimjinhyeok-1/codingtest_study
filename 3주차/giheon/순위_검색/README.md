# [순위 검색]

### 1. 접근 방식
 - 확실히 데이터베이스 관련 문제는 아직 숙련도가 많이 부족한 것 같음.

### 2. 핵심 로직
 - itertools.combinations 사용해서 만들 수 있는 모든 경우의 수에 대해 검색 키 생성 및 값을 오름차순 정렬.
 - bisect_left를 활용하여 기준 점수가 들어갈 수 있는 가장 왼쪽의 인덱스 반환. 그걸로 기준 점수 이상인 갯수 반환.

### 3. 시간 복잡도
 - O(NlogN + MlogN) 정렬+이진탐색.

### 4. 느낀 점 / 어려웠던 점
 - 전에 봤던 문제이긴 한데 별로 안 중요한 유형이라고 생각해서 대충 보고 넘어갔던 문제라 기억이 안났음.

### 5. 풀이 시간
 - 정답 찾아보고 풀음.
