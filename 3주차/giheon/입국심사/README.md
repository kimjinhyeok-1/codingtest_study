# [입국심사]

### 1. 접근 방식
 - n이 10억이여서 뭔가 규칙을 찾아서 단순 연산만으로 답이 도출될 수 있도록 해야한다고 생각했음.
 - 이분탐색은 대충 생각만 해봤는데 구체적으로 어떻게 구현해야 할 지 떠오르지 않아서 못 풀었음.

### 2. 핵심 로직
 - mid를 답이라고 가정했을 때 해당 시간안에 처리할 수 있는 사람 횟수를 계산해서 n보다 크면 right를 mid-1로 하고 n보다 작으면 left를 mid+1로 해서 이분탐색

### 3. 시간 복잡도
 - K = max(times)*n
 - O(NlogK)

### 4. 느낀 점 / 어려웠던 점
 - 답 찾아보고 풀었음. 이분 탐색을 활용할 때 내가 도출해야 하는 답을 기준으로 이분탐색을 해야하는구나 깨달음.
 - 이분탐색 문제도 좀 풀어봐야겠다고 생각함.

### 5. 풀이 시간
 - 30분 고민하다가 정답 찾아봄
