# [H-index]

### 1. 접근 방식
- 처음에 정렬하고 bisect_left로 했는데 잘못 풀었음 0부터 모든 값을 순회해야되는데 배열안에 있는 값으로만 순회해서오류남
- [100,100,100] 이렇게 있어도 3이 정답인데 첫번째 풀이로는 택도 없었음

### 2. 핵심 로직
- 그냥 0부터 배열 길이만큼 순회하면서 각각 h 구하고 해당 인용 횟수가 h 이상이면 바로 리턴하는 구조가 정답

### 3. 시간 복잡도
- 정렬 때문에 O(NlogN)

### 4. 느낀 점 / 어려웠던 점
- 정렬 재밌누

### 5. 풀이 시간
- 20분
