# [순위_검색]

### 1. 접근 방식
- 완탐으로 들어갈려했는데 50억번 연산이라 ㅈㅈ
- key값을 미리 만들어서 defaultdict(list) 형태로 하는건 충분히 생각해볼만 한것 같음

### 2. 핵심 로직
- 각 info에 들어있는 info 별로 16가지 종류를 모두 만들어서 각각 score 점수를 다 넣어줌
- 넣어준 점수를 오름차순으로 정렬하고 이분 탐색을 이용해서 몇명 합격할 수 있는지 계산

### 3. 시간 복잡도
- 전처리 O(N * 16) 정렬하는데 NlogN 가능가능

### 4. 느낀 점 / 어려웠던 점
- 흠,, 일단 key값을 만들어서 점수 넣는 부분까지 생각이 한번에 닿지 못했던 것 같음
- 다음주에 한번더 풀어봐야될 것 같음,, ㅠ 로직은 ai, 블로그 참고 좀 했음
